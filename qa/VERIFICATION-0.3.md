# BIT DRAW 0.3 驗證紀錄

2026-10-29。Windows、Node.js、Codex 內建瀏覽器，1280 × 720 與最後 1055 × 612 的實際視窗預覽（未設定 viewport override）。

- 35 項核心測試通過。新增測試涵蓋原圖分析、抽樣占比與確定性、RGB 混色端點、色卡合併去重、容許色差替換、透明度／選區保留、四向／八向區域分割、固定起始色避免漸層串連、區域填色、三種描邊幾何、描邊圖層獨立性、復原與序列化、參數／鎖定保護、HSV 往返及 12 組預設色盤。
- 瀏覽器原圖分析：384 × 384 程式繪製紋理示例，以 65,536 個取樣得到 16 個代表色，顯示抽樣估計與占比。成功建立工作色盤，指定 A／B，儲存混合色與合併色卡。
- 自訂選色輸入 #256DCD，顯示 RGB 37／109／205，成功設為前景色與加入色盤。檢查色彩平面、色相滑桿及原色／新色排版。
- 預設色盤「霓虹夜城 16」成功建立可編輯副本。
- 原圖分析色精確替換找不到匹配時顯示提示；容許值調至 20，A／B→混合色成功匹配 359 個像素，可復原。
- 區域分析在測試圖找出 68 個相連色塊；列表選取、以前景色填入及復原均成功。直接點畫布選取 #52（12 px），沒有新增筆畫或復原步驟。
- 外描邊預覽顯示 230 個像素，套用後新增獨立描邊圖層。保存為 studio-v3.bitdraw.json，重開後保留 2 圖層及 3 組色盤。
- 區域彩色標記開啟時匯出 48 × 48 PNG，Pillow 解碼 RGBA 與 Node composite() 的 9,216 通道值完全相同。證明區域標記不會輸出；composite-v3.rgba 留存比對基準。
- CLI 成功執行 examples/studio-commands.json，輸出 cli-v3.bitdraw.json，包含新增原圖色盤、混合色與描邊。
- 瀏覽器 console 未見 error／warn；新增 JS 模組通過 Node 語法檢查。
