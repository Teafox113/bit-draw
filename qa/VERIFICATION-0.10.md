# BIT DRAW 0.10 驗證

98 項 Node 測試通過（包含 loopback HTTP），新增遮罩範圍驗證、先去背再平均取樣、儲存重開再重建一致、平衡細節強度、五官縮色權重、摘要不洩出遮罩 runs、無人臉時不捏造保護區、預演與復原。

實圖對照見 [可離線開啟的比較頁](../docs/quality-v10.html)。照片 2250×2848，動漫 1110×2100，另把動漫透明素材合成至咖啡照片做可量測的複雜背景壓力測試。測試 96×74、48×48、180×180，24 色上限、二值透明；原圖 SHA-256、壓縮重開後圖層與遮罩均驗證一致。比較固定相同裁切與尺寸，沒有手繪保護座標。小圖是自動臉部裁切，全圖是 180×180。

精細 U²-Net 在 NASA 照片中排除了旗幟與太空梭模型；手指附近仍有少量誤刪。動漫複雜背景單一合成圖的 mask IoU 從 0.7683 到 0.7983：漏掉角色的像素 167409→5488，但誤保留背景 124121→279632，咖啡杯仍被當作顯著主體。這是取捨與限制，不代表任意圖片的準確率。輕量模型 IoU 為 0.7720。所有推論均標記 review，未宣稱人物語意分割。

精細模型在本機 Node/WASM 初次照片分析約 9.1 秒，複雜動漫約 8.9 秒；輕量模型約 1.5–1.8 秒。瀏覽器初次精細照片分析約 7 秒，同來源流程快取後約 72 ms。時間依機器及負載而變；不是純縮圖效能比較。原有 alpha 輪廓直接保留，不執行模型；同來源相同模式只推論一次。

瀏覽器代理已驗證：新匯入照片 → 模型輪廓預覽 → 保存並執行 smart-cutout 流程 → dryRun 不變更版本 → 提交 → 原生 PNG → 保存 v5 壓縮專案 → 重開。模型與完整遮罩不進入代理摘要；JSON 請求 bytes 不等於實際 Token 數。

專案內格式升為 v5，避免舊編輯器忽略遮罩重建出背景；仍可讀 v1–v4，外層 bitdraw-packed v1 不變。模型不嵌入專案。Git 不包含權杖、node_modules、模型二進位或大型實驗專案；clone 後執行 npm ci 與 npm run setup:models。歷史 qa 腳本依賴本機未納入 Git 的實驗原圖／專案；一般 npm test 不需要這些素材。
