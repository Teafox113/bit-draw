# BIT DRAW 0.11 驗證

日期：2026-11-18。103 項 Node 測試通過，包含本機 HTTP 橋接。新測試涵蓋動漫模型的長寬比與補邊、RGB/255、機率不拉伸、亮暗細節取樣、保護區外不變、非法參數回復、透明來源略過推論、專案往返及長工作不中斷 session。

## 可重現實圖比較

執行 `npm ci --ignore-scripts`、`npm run setup:models`、`npm run setup:anime`，再執行 `npm run test:images` 和 `node qa/package-v11.mjs`。素材已納入 `qa/fixtures-v11`，來源、尺寸、授權與 SHA-256 見該目錄 `sources.json`；不依賴以前未提交的實驗檔。`qa/prepare-fixtures-v11.mjs` 是最初從舊實驗專案整理素材的工具，一般重現不需執行。

比較頁：[quality-v11.html](../docs/quality-v11.html)，可下載後離線開啟。測試使用 1110 × 2100 的 Wikipe-tan、809 × 1024 的 NASA 人像，以及 600 × 400 的咖啡照片。兩張複雜背景由實際授權圖片合成，原始角色 alpha 只供評分，不提供給去背模型；這是可量測壓力測試，不是真實動漫場景的通用基準。

| 合成背景 | 通用模型 IoU | 動漫模型 IoU | 誤留背景 px：之前 → 之後 | 誤刪角色 px：之前 → 之後 |
|---|---:|---:|---:|---:|
| 咖啡與木桌 | 0.7983 | 0.9756 | 279,632 → 21,311 | 5,488 → 6,929 |
| 含真人的 NASA 背景 | 0.6793 | 0.7229 | 283,786 → 426,997 | 170,942 → 5,544 |

咖啡杯殘留明顯減少，誤留背景降低約 92.4%，但角色細邊仍有少量誤刪。含真人背景雖少漏掉角色，背景誤留反而增加；自動臉框亦可能偏移，不能視為成功去背。所有模型結果保留 review 標記。

每個案例輸出 32 × 32、48 × 48、96 × 74、180 × 180，24 色、二值 alpha。前三種固定相同自動臉部裁切，180 × 180 保留全圖構圖；未手工修正保護區。比較通用模型＋balanced 與動漫模型＋crisp；NASA 單人照片維持 quality＋balanced 作回歸對照。透明來源不執行模型。

清晰模式讓原有亮點與深色線條在縮小後更明顯，但 32 px 仍有鋸齒與方塊化；不存在於原圖或沒辨識到的五官不會自動生成。沒有以客觀評分宣稱所有五官更好看。

驗證原生尺寸、色數上限、二值 alpha、原圖 SHA-256 不變，以及壓縮專案重開後像素和去背遮罩相同。完整資料在本機生成的 `qa/real-v11/report.json`，比較頁包含指標和全部圖像。

## 本機效能與代理流程

Node／單執行緒 WASM：動漫模型在兩張合成圖約 12.5–12.6 秒；同來源、同模型快取後不重跑。瀏覽器首次分析 1110 × 2100 咖啡合成圖約 16.1 秒，快取後完整流程套用約 60 ms。含模型初始化與當時機器負載，不是跨機器效能保證。

`qa/verify-live-v11.mjs SESSION` 已在真實工作台完成：匯入完整 PNG → 模型輪廓預覽 → 保存 anime-icon 流程 → dryRun 不改 revision → 提交 → 原生 96 × 74 PNG → 保存 v5 壓縮專案 → 重開 → PNG 位元組一致。代理回覆不包含模型或完整遮罩 runs。

瀏覽器可選「動漫角色去背」與「清晰／平衡」取樣；原圖左右比較與工作像素圖保留。已保存流程定義可重用，只傳 ID、版本與參數，尚未做實際模型 Token 用量基準。
